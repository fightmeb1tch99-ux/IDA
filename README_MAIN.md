# IDA - Инновационный динамический помощник v 0.1

**IDA** (Инновационный динамический помощник) — это полнофункциональный AI ассистент с поддержкой GPT, инструментов и красивым мобильным интерфейсом.

## 🚀 Возможности

- ✅ **Умный чат** - Интеграция с OpenAI GPT для интеллектуальных ответов
- ✅ **Инструменты** - Время, дата, поиск в интернете, создание файлов
- ✅ **Мобильное приложение** - Красивый интерфейс для Nothing Phone 2
- ✅ **Поддержка русского языка** - На русском, якутском и английском
- ✅ **История диалогов** - Сохранение и контекст разговоров
- ✅ **Безопасность** - Защита от инъекций и валидация данных
- ✅ **Логирование** - Полный лог всех действий

## 📁 Структура проекта

```
SYP-PROJECT/
├── main.py              # Главный файл для запуска IDA
├── brain.py             # Логика NLP и обработка команд
├── memory_manager.py    # Управление памятью и историей
├── logger.py            # Система логирования
├── config.py            # Конфигурация
├── tools/
│   └── tools.py         # Реализация инструментов
├── memory/
│   └── memory.json      # Сохраненная память
├── logs/                # Логи приложения
├── mobile-app/          # Мобильное приложение (Expo/React Native)
├── README.md            # Документация на английском
├── README_RU.md         # Документация на русском
└── README_SAH.md        # Документация на якутском
```

## 🛠️ Установка

### На компьютере (Python)

```bash
git clone https://github.com/fightmeb1tch99-ux/SYP-PROJECT
cd SYP-PROJECT
git checkout dev
pip install -r requirements.txt
python3 main.py
```

### В Termux на Nothing Phone 2

```bash
pkg update && pkg upgrade -y
pkg install python git -y
git clone https://github.com/fightmeb1tch99-ux/SYP-PROJECT
cd SYP-PROJECT
git checkout dev
python3 main.py
```

## 📱 Мобильное приложение

### Запуск в Termux

```bash
cd ~/SYP_PROJECT/mobile-app
npm install
npm start
```

Потом отсканируй QR-код в **Expo Go**.

### Настройка OpenAI API

1. Получи API ключ на https://platform.openai.com/api-keys
2. В файле `mobile-app/App.js` замени:
   ```javascript
   const OPENAI_API_KEY = 'sk-proj-...';
   ```
3. Запусти приложение

## 💬 Использование

### Текстовый чат в Termux

```bash
python3 main.py "Привет, как дела?"
python3 main.py "Сколько сейчас времени?"
python3 main.py "Создай файл test.txt"
```

### Интерактивный режим

```bash
python3 main.py
# Введи свой запрос и нажми Enter
```

## 🔑 Переменные окружения

```bash
# OpenAI API ключ
export OPENAI_API_KEY="sk-proj-..."

# Путь к памяти (опционально)
export IDA_MEMORY_PATH="./memory/memory.json"
```

## 📚 Команды

| Команда | Описание |
|---------|---------|
| `--help` | Показать справку |
| `--stats` | Показать статистику |
| `Сколько времени?` | Получить текущее время |
| `Какая дата?` | Получить текущую дату |
| `Создай файл [имя]` | Создать файл |
| `Найди [запрос]` | Поиск в интернете |
| Любой текст | Обсудить с IDA |
