# 📚 База знаний IDA (RAG System)

IDA теперь умеет работать с вашими личными документами!

## Как это работает
IDA может искать информацию в файлах форматов `.txt` и `.pdf`, которые находятся в папке `knowledge/`.

## Как использовать
1. Создайте папку `knowledge` в корне проекта (если её нет).
2. Положите туда свои документы (например, конспекты, инструкции или книги).
3. Спросите IDA:
   - «Спроси базу: как настроить сервер?»
   - «Что говорится в документах о проекте X?»
   - «Найди в базе информацию про рецепты.»

## Технические детали
- Система использует **RAG (Retrieval-Augmented Generation)**.
- При запросе IDA сначала ищет релевантные куски текста в ваших файлах.
- Затем она передает найденную информацию в нейросеть (LLM) для формирования точного ответа.
