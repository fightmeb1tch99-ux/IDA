# 📱 IDA v4.0 Mobile App — React Native + Expo

Мобильное приложение для AI ассистента IDA с красивым интерфейсом, голосовым помощником и темной темой.

**Создатель:** Григорьев Айтал Григорьевич (@Mareioak)

## ✨ Возможности

✅ **Красивый чат интерфейс** — Futuristic дизайн  
✅ **Интеграция с Groq API** — Бесплатный и быстрый LLM  
✅ **Голосовой помощник** — Распознавание и синтез речи

✅ **Кроссплатформенность** — iOS и Android

## 🚀 Установка

### На Android (Termux)

```bash
# 1. Установи Node.js
pkg install nodejs -y

# 2. Перейди в папку приложения
cd ~/IDA/mobile-app

# 3. Установи зависимости
npm install

# 4. Запусти приложение
npm start
```

### На ПК (Windows/macOS/Linux)

```bash
# 1. Установи Node.js
# https://nodejs.org/

# 2. Перейди в папку приложения
cd IDA/mobile-app

# 3. Установи зависимости
npm install

# 4. Запусти приложение
npm start
```

## 📱 Запуск на телефоне

### Способ 1: Expo Go (рекомендуется)

1. Установи **Expo Go** из Google Play Store или App Store
2. Запусти приложение командой выше
3. Отсканируй QR-код в Expo Go
4. Приложение загрузится на телефон!

### Способ 2: Встроенный браузер

```bash
# Откроется в браузере на http://localhost:8081
npm start
```

## ⚙️ Настройка Groq API

### Вариант 1: Через переменные окружения

```bash
# Создай файл .env
cp .env.example .env

# Добавь свой Groq API ключ
GROQ_API_KEY="gsk_..."
```

### Вариант 2: Через App.js

1. Открой файл `App.js`
2. Найди строку: `const GROQ_API_KEY = process.env.GROQ_API_KEY;`
3. Замени на свой API ключ от Groq

## 🐛 Решение проблем

### Приложение не запускается

```bash
# Очистка кэша
npm cache clean --force

# Переустановка зависимостей
rm -rf node_modules package-lock.json
npm install

# Перезапуск
npm start
```

### QR-код не сканируется

1. Убедись, что телефон подключен к интернету
2. Убедись, что Expo Go установлен
3. Попробуй перезагрузить приложение

### Groq API не работает

1. Проверь, что ключ установлен правильно
2. Проверь, что у тебя есть интернет
3. Проверь, что ключ активен на сайте Groq
