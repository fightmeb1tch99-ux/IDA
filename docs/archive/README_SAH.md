## ✨ IDA v4.0 кыахтара

### 🔒 Куттал суох буолуута
- **Хааччахтаммыт хамаандалар** — Көҥүллэммит эрэ хамаандалары толорор
- **Суолу харыстааһын** — Файллары кытта үлэни куттала суох сиринэн хааччахтыыр
- **Киирэр дааннайдары бэрэбиэркэлээһин** — Бары киирэр тыллары хонтуруоллуур
- **Инъекциялар аҕаллара** — Groq API инъекциялар аҕаллаах

### 📝 Логтааһын уонна Кэтэбил
- **Толору логтааһын** — Бары дьайыылары уонна алҕастары `logs/` папкаҕа суруйар
- **Алҕастары көрдөөһүн** — Тупсарарга аналлаах сиһилии отчеттор
- **Дьайыылар историята** — Бары хамаандалар өйгө тутуллар

### 🧠 Өйө (LLM)
- **Groq API** — Суох уонна тиксэ LLM OpenAI-та ордун
- **Кэпсэтии** — IDA дьиҥнээх GPT курдук кэпсэтиини өйүүр кыахтаах
- **Контекһы өйдөөһүн** — Агент урукку кэпсэтиини өйдүүр
- **Тыллары ырытыы** — Киһи тылын курдук өйдүүр

### 💾 Өйгө тутуу (Memory)
- **Өйгө тутуу** — Барыта JSON файлыгар суруллар
- **Автоматическай бэкаптар** — Хас суруйуу аайы резервнай копия оҥорор
- **Тиксэ киириэ** — Сорук туттар дааннайдар кэш туһуллар

### 🎤 Сэһэн туһунаах

- **Сэһэ синтез** — Сэһэнэ хаваарар

## 🚀 Тиксэ туруоруу

### Android та (Termux)

```bash
# 1. Ирдэбиллэри туруор
pkg install python git -y
pip install groq

# 2. Проектты клонируй
git clone https://github.com/fightmeb1tch99-ux/SYP-PROJECT IDA
cd IDA
git checkout dev

# 3. Groq API ключ туруор
export GROQ_API_KEY="gsk_..."

# 4. IDA ыытыы
python3 main.py
```

### ПК та (Windows/macOS/Linux)

```bash
# 1. Python 3.9+ туруор
# https://www.python.org/downloads/

# 2. Проектты клонируй
git clone https://github.com/fightmeb1tch99-ux/SYP-PROJECT IDA
cd IDA
git checkout dev

# 3. Ирдэбиллэри туруор
pip install -r requirements.txt

# 4. Groq API ключ туруор
export GROQ_API_KEY="gsk_..."

# 5. IDA ыытыы
python3 main.py
```

### IDA ыытыы

```bash
# Интерактивнай режим
python3 main.py

# Бирэ хамаанда
python3 main.py "Бириэмэ төһө буолла?"

# Туһунаа
python3 main.py --help

# Статистика
python3 main.py --stats
```

## 📁 Проектын структура

```
IDA/
├── main.py                  # Киирэр сиһилии, оркестратор
├── brain.py                 # NLP, хамаандалары парсинг, LLM (Groq)
├── groq_client.py           # Groq API клиент
├── config.py                # Бары туруоруу
├── logger.py                # Логтааһын
├── ida_system.py            # Системнай инструменнар
├── tools/
│   └── tools.py             # Инструменнар: бириэмэ, оҕото, калькулятор...
├── memory/
│   └── memory.json          # Өйгө тутуу
├── landing.html             # Лендинг-сахалта
├── mobile-app/              # React Native аппликейшэн (Expo)
├── README_V4.md             # Толору туһунаа v4.0
├── README_RU.md             # README русскай
├── README_SAH.md            # README сахалаа
├── .env.example             # Шаблон окружения
├── requirements.txt         # Python ирдэбиллэр
└── README.md                # README англис
```

## ⚙️ Туруоруу (config.py)

| Параметр | Сүүрэ | Быһаарыыта |
|---|---|---|
| `LLM_MODEL` | `mixtral-8x7b-32768` | Groq модель |
| `LLM_TEMPERATURE` | `0.7` | Оҥоруу температура |
| `CONTEXT_WINDOW` | `10` | Хас сообщение өйдүүр |
| `ENABLE_WEATHER` | `True` | wttr.in аҕаллыгар оҕото |
| `ENABLE_CALCULATOR` | `True` | Туруу калькулятор |
| `ENABLE_NOTES` | `True` | Өйгө система |
| `GROQ_API_KEY` | `env` | Groq API ключ |
