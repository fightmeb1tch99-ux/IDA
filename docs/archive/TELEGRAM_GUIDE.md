# 🤖 Настройка Telegram-бота для IDA

Теперь вы можете общаться с IDA прямо через Telegram!

## 1. Получение токена
1. Найдите в Telegram бота [@BotFather](https://t.me/botfather).
2. Отправьте команду `/newbot`.
3. Следуйте инструкциям и получите **API Token**.

## 2. Настройка окружения
1. Откройте файл `.env` в корне проекта.
2. Добавьте туда ваш токен:
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_здесь
   ```
3. (Опционально) Чтобы бот отвечал только вам, добавьте ваш Telegram ID:
   ```env
   ALLOWED_USER_IDS=123456789
   ```
   *Свой ID можно узнать у бота [@userinfobot](https://t.me/userinfobot).*

## 3. Запуск
Установите зависимости и запустите бота:
```bash
pip install -r requirements.txt
python telegram_bot.py
```

## 4. Команды в Telegram
- `/start` — начать общение.
- `/help` — список доступных инструментов.
- Просто пишите текст, как в обычном чате с IDA.
