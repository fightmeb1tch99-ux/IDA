# AI Camera Brain 🧠📹

> **Интеллектуальная система компьютерного зрения с функцией самообучения и долгосрочной памяти, работающая на базе бесплатных и открытых AI API.**

---

## 🌟 О проекте

**AI Camera Brain** — это программа, которая превращает вашу обычную веб-камеру в умного агента с искусственным интеллектом. Камера не просто транслирует видеопоток, а **постоянно анализирует окружение, видит всё происходящее, распознает объекты, запоминает события и обучается со временем**.

Проект разработан с поддержкой бесплатных и открытых AI API (включая OpenAI-совместимые бесплатные эндпоинты, Groq, Ollama, Gemini Flash и другие провайдеры с щедрыми бесплатными лимитами). Встроенная система долговременной памяти сохраняет историю наблюдений и статистику появления объектов в файл `camera_memory.json`.

---

## 🚀 Ключевые возможности

- **🧠 Долгосрочная память и обучение:** Система накапливает знания об увиденных объектах и людях, ведет статистику и передает контекст прошлых наблюдений текущему анализу.
- **👁️ Мультимодальный анализ в реальном времени:** Автоматический захват кадров с веб-камеры и отправка в мультимодальную языковую модель для глубокого описания сцены.
- **🆓 Бесплатные и открытые API:** Поддержка любых OpenAI-совместимых бесплатных эндпоинтов, локальных моделей через Ollama или облачных провайдеров (Groq, Google Gemini) [1].
- **🖥️ Интерактивный HUD (Heads-Up Display):** Наложение результатов анализа и обнаруженных объектов прямо на видеопоток в OpenCV в реальном времени.
- **⌨️ Ручное и автоматическое управление:** Возможность настраивать интервал анализа кадров, принудительно вызывать анализ клавишей `s` и завершать работу клавишей `q`.
- **⚙️ Интерактивная настройка:** Удобный мастер настройки (`--setup`) для ввода конфигурации API.

## 🛠️ Установка и запуск

### 1. Клонирование репозитория и установка зависимостей

Убедитесь, что у вас установлены **Python 3.10+** и веб-камера.

```bash
git clone https://github.com/fightmeb1tch99-ux/SYP-PROJECT.git
cd SYP-PROJECT
pip install -r requirements.txt
```

### 2. Настройка API

Вы можете настроить подключение к бесплатному AI API через интерактивный мастер:

```bash
python main.py --setup
```

Либо создать файл `.env` или `config.json` в корне проекта со следующими параметрами:

```json
{
  "api_url": "https://api.openai.com/v1",
  "api_key": "ваш_бесплатный_или_прокси_ключ",
  "model": "gpt-4o-mini",
  "capture_interval": 5,
  "camera_index": 0
}
```

### 3. Запуск AI Camera Brain

```bash
python main.py
```

#### Дополнительные аргументы командной строки:
- `--camera <index>` — выбор индекса камеры (по умолчанию `0`).
- `--interval <seconds>` — интервал между запросами к ИИ в секундах (по умолчанию `5`).
- `--model <name>` — имя используемой AI-модели.
- `--setup` — запуск интерактивного мастера настройки.

---

## ⌨️ Управление во время работы

- Нажмите **`s`** (Snapshot) для принудительного моментального анализа текущего кадра.
- Нажмите **`q`** (Quit) для безопасного выхода из программы.

## 📊 Архитектура памяти

Все наблюдения и обнаруженные объекты сохраняются в структурированном виде в файле `camera_memory.json`. Пример структуры памяти:

```json
{
  "observations": [
    {
      "timestamp": "2026-08-08T12:00:00.000000",
      "analysis": "В комнате за рабочим столом сидит человек и работает за ноутбуком. На столе стоит чашка кофе.",
      "objects": ["человек", "ноутбук", "чашка кофе", "стол"]
    }
  ],
  "learned_objects": {
    "человек": {
      "first_seen": "2026-08-08T12:00:00.000000",
      "last_seen": "2026-08-08T12:05:00.000000",
      "count": 12
    }
  },
  "total_sessions": 3
}
```
