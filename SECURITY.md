# 🛡️ Безопасность проекта IDA

Безопасность пользователей и их данных является нашим приоритетом. Пожалуйста, следуйте этим рекомендациям при использовании и разработке IDA.

## 🔑 Управление секретами
- **Никогда** не коммитьте файл `.env` в Git. Он добавлен в `.gitignore` по умолчанию.
- Используйте `.env.example` как шаблон для ваших ключей.
- Если вы разворачиваете IDA на сервере, используйте переменные окружения ОС вместо файлов.

## 🐚 Выполнение команд
- IDA использует **белый список (whitelist)** для выполнения shell-команд.
- Список разрешенных команд находится в `config.py` (`SAFE_COMMANDS`).
- Не добавляйте в этот список команды, которые могут изменять системные файлы или предоставлять удаленный доступ (например, `rm`, `chmod`, `nc`).

## 🧮 Вычисления
- Калькулятор использует безопасную фильтрацию ввода. Разрешены только цифры и математические операторы. Любые буквенные символы блокируются до выполнения.

## 📂 Файловая система
- Создание файлов ограничено директорией `created_files/`.
- Встроена защита от **Path Traversal** (блокировка `..` и абсолютных путей).

## 📱 Мобильное приложение
- В текущей версии API-ключ вставляется в код приложения. **Внимание:** Это безопасно только для личного использования. 
- Для публичного релиза рекомендуется использовать прокси-сервер, чтобы скрыть ключ от конечных пользователей.

## 🐛 Сообщить об уязвимости
Если вы нашли проблему безопасности, пожалуйста, создайте [Issue](https://github.com/fightmeb1tch99-ux/SYP-PROJECT/issues) с пометкой "Security" или свяжитесь с автором напрямую.
