Возможности IDA

Всё что нужно умному помощнику — в одном проекте

🧠

GPT-интеграция

Умные ответы через OpenAI API. Поддержка моделей gpt-5-nano, gpt-5-mini и gpt-5. Контекст последних 10 сообщений.

🌤

Погода в реальном времени

Текущая погода через wttr.in — без API-ключа. Просто спроси «Какая погода?»

🧮

Встроенный калькулятор

«Посчитай 15 * 7 + 3» — мгновенный результат. Безопасное вычисление без eval-уязвимостей.

📝

Заметки

«Запомни купить молоко» — сохраняет заметки с временной меткой. «Покажи заметки» — список всех записей.

🎤

Голосовой ассистент

Мобильное приложение на React Native с анимированным аватаром и голосовым вводом.

🔒

Безопасность

Whitelist команд, защита от path traversal, валидация ввода, безопасный eval для калькулятора.

💾

Память и история

Автосохранение диалогов, резервные копии памяти, счётчик взаимодействий и статистика.

🔍

Поиск в интернете

Быстрый поиск через DuckDuckGo Instant Answer API без дополнительных ключей.

⚙️

Гибкая настройка

Всё в config.py: модель, логи, таймауты, feature flags. Поддержка .env для секретов.

Быстрый старт

Три шага до запуска IDA

🐍 Python агент

Запусти IDA в терминале — интерактивный режим с полным набором инструментов.

git clone https://github.com/fightmeb1tch99-ux/SYP-PROJECT
cd SYP-PROJECT
pip install -r requirements.txt
python3 main.py

📱 Мобильное приложение

React Native + Expo. Голосовой ассистент, быстрые команды, тёмная тема.

cd mobile-app
npm install
npx expo start
