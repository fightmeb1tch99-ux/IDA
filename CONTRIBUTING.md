# Contributing to IDA

Спасибо, что хочешь помочь развитию IDA!

## Как начать

1. Форкни репозиторий
2. Создай ветку от `main`:
   ```bash
   git checkout -b feature/my-cool-feature
   ```
3. Внеси изменения
4. Сделай коммит с понятным сообщением
5. Открой Pull Request

## Правила

- **Безопасность** — никогда не добавляй `shell=True` и не ослабляй whitelist команд без обсуждения.
- **Код** — пиши чисто, с type hints где возможно, и с docstring.
- **Документация** — если добавляешь новую возможность, обнови README или ROADMAP.
- **Тесты** — желательно покрывать новые инструменты тестами.
- **Язык** — комментарии и сообщения можно на русском или английском.

## Структура (текущая)

Сейчас в проекте есть дублирование некоторых папок (`client`/`client-web`, `server`/`server-web` и т.д.).  
Мы планируем постепенную очистку. Если хочешь помочь с рефакторингом структуры — сначала создай Issue.

## Что особенно нужно

- Помощь с RAG
- Улучшение голоса (STT/TTS)
- Очистка структуры monorepo
- Тесты
- Документация на якутском
