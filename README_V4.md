## 🤖 О проекте

**IDA v4.0** — это мощный AI-помощник, который работает везде: в Termux на Android, на ПК, в мобильном приложении и в веб-браузере.

### Основные характеристики:

- ✅ **Многоязычный** - Русский, якутский, английский
- ✅ **Бесплатный LLM** - Groq API (без платежей!)
- ✅ **Голосовой помощник** - Распознавание и синтез речи
- ✅ **Мобильное приложение** - React Native + Expo
- ✅ **Веб-интерфейс** - Красивый лэндинг
- ✅ **Инструменты** - Время, дата, файлы, поиск
- ✅ **Безопасность** - Защита от инъекций и уязвимостей
- ✅ **Логирование** - Полная история всех действий

## 🎯 Возможности

### 💬 Общение с ИИ
```bash
python3 main.py "Привет, как дела?"
```

### 🎤 Голосовой ввод
```bash
python3 main.py
# Напиши: "редактор" или "editor"
# Говори в микрофон
```

### 📝 Редактор кода
```bash
python3 main.py
# Напиши: "редактор"
# Начни писать код
```

### ⏰ Инструменты
- `Какое время?` - текущее время
- `Какая дата?` - текущая дата
- `Посчитай 15 * 7` - калькулятор
- `Создай файл notes.txt` - создание файлов

### 📱 Мобильное приложение
```bash
cd mobile-app
npm start
# Отсканируй QR-код в Expo Go
```

### 🌐 Веб-страница
Открой `landing.html` в браузере

## 🚀 Быстрый старт

### На Android (Termux)

```bash
# 1. Установи зависимости
pkg install python git -y
pip install groq

# 2. Клонируй проект
git clone https://github.com/fightmeb1tch99-ux/SYP-PROJECT IDA
cd IDA
git checkout dev

# 3. Установи Groq API ключ
export GROQ_API_KEY="gsk_..."

# 4. Запусти IDA
python3 main.py
```

### На ПК (Windows/macOS/Linux)

```bash
# 1. Установи Python 3.9+
# https://www.python.org/downloads/

# 2. Клонируй проект
git clone https://github.com/fightmeb1tch99-ux/SYP-PROJECT IDA
cd IDA
git checkout dev

# 3. Установи зависимости
pip install -r requirements.txt

# 4. Установи Groq API ключ
export GROQ_API_KEY="gsk_..."

# 5. Запусти IDA
python3 main.py
```

### Мобильное приложение

```bash
# 1. Установи Node.js и npm
# https://nodejs.org/

# 2. Перейди в папку приложения
cd mobile-app

# 3. Установи зависимости
npm install

# 4. Запусти приложение
npm start

# 5. Отсканируй QR-код в Expo Go
```
