# 🤖 IDA v 0.1 - Продвинутый ИИ-Агент

Интеллектуальный ИИ-агент с функциями безопасности, логирования и интеграцией с современными языковыми моделями (LLM).

## ✨ Возможности

### 🔒 Безопасность
- **Белый список команд**: Выполнение только разрешенных системных команд.
- **Защита путей**: Ограничение операций с файлами безопасными директориями.
- **Валидация ввода**: Тщательная проверка всех входящих данных.

### 📝 Логирование и Мониторинг
- **Полное логирование**: Запись всех действий и ошибок в папку `logs/`.
- **Отслеживание ошибок**: Детальные отчеты для отладки.

### 🧠 Интеллект (LLM)
- **Поддержка разговора**: IDA может поддерживать полноценный диалог как настоящий GPT.
- **Понимание контекста**: Агент помнит историю общения.
- **Гибкий парсинг**: Понимает команды на естественном языке.

### 💾 Управление памятью
- **Постоянное хранение**: Память сохраняется в JSON.
- **Автоматические бэкапы**: Резервное копирование перед каждым сохранением.

## 🛠️ Доступные инструменты

| Инструмент | Команда | Описание |
|------------|---------|----------|
| **Время** | "Который час?" | Текущее время |
| **Дата** | "Какое сегодня число?" | Текущая дата |
| **Файлы** | "Создай файл [имя]" | Безопасное создание файлов |
| **Команды** | "Выполни [команда]" | Запуск разрешенных команд |
| **Поиск** | "Найди [запрос]" | Поиск в DuckDuckGo |

## 🚀 Установка и Запуск

### Требования
- Python 3.7+
- API ключ (для работы функций GPT)

### Запуск
```bash
git clone https://github.com/fightmeb1tch99-ux/SYP-PROJECT
cd SYP-PROJECT
git checkout dev
python3 main.py
```

## 📁 Структура проекта
- `main.py` — Точка входа.
- `brain.py` — "Мозг" агента и логика общения.
- `memory_manager.py` — Работа с памятью.
- `logger.py` — Логирование.
- `config.py` — Настройки.
- `tools/` — Инструменты.
