# IDA на смартфоне (Android и iOS)

Дата обновления: **2026-10-10** (unified API)

IDA работает с телефона как компаньон в стиле **Джарвиса**: чат, статус связи, голос (базовый), Live2D-аватар на вебе реагирует на диалог через realtime.

## 1. Запуск мозга на компьютере

```bash
cd IDA
./start.sh
```

Поднимается (Unified API):
- всё на одном порту **8000** (HTTP + WebSocket)

Раньше отдельно, теперь:
- HTTP API / веб-чат → `http://ПК:8000`
- Realtime WebSocket → `ws://ПК:8000/ws`

Узнай IP компьютера в Wi‑Fi:
- Linux/macOS: `ip a` или `ifconfig`
- Windows: `ipconfig`

Пример: `192.168.1.42`

## 2. Expo-приложение (ida-app)

```bash
cd ida-app
# создай .env
echo "EXPO_PUBLIC_API_URL=http://192.168.1.42:8000" > .env
echo "EXPO_PUBLIC_WS_URL=ws://192.168.1.42:8000/ws" >> .env

npx expo start
```

- **Android**: отсканируй QR в Expo Go (одна Wi‑Fi сеть с ПК).
- **iOS**: то же через Camera / Expo Go.
- Эмулятор: можно `http://10.0.2.2:8000` (Android emulator → host).

Телефон и ПК должны быть в **одной сети**. `localhost` на телефоне — это сам телефон, не твой ПК.

## 3. Что умеет мобильный клиент

- Чат с IDA (JARVIS-режим: краткие ответы, действия, инициатива)
- Индикатор «на связи / нет связи»
- Голосовая кнопка (заготовка под native STT / Whisper)
- Те же инструменты, что и на ПК (время, погода, заметки, поиск…)

## 4. Аватар как Джарвис

На веб-дашборде Live2D получает события:

| state | смысл |
|-------|--------|
| `thinking` | IDA думает |
| `speaking` | IDA отвечает (рот/анимация) |
| `idle` | ждёт / слушает |

События идут по `ws://…/ws` типом `avatar_state`.

## 5. Troubleshooting

| Проблема | Решение |
|----------|---------|
| Нет связи с телефона | firewall, один Wi‑Fi, верный IP, `./start.sh` запущен |
| Expo не видит API | `EXPO_PUBLIC_API_URL` без опечаток, порт 8000 открыт |
| CORS | backend уже с `allow_origins=["*"]` |
