# 🗺️ Роадмап развития IDA (Инновационный Динамический Помощник)

Этот документ описывает планы по развитию проекта IDA на ближайшее будущее. Мы стремимся сделать IDA не просто чат-ботом, а полноценным персональным ассистентом.

---

## 🟢 Этап 1: Стабилизация и Основы (v2.0 - v2.5) — *Текущий этап*
*Фокус на надежности, безопасности и базовом удобстве.*

- [x] **Рефакторинг кода:** Переход на модульную архитектуру.
- [x] **Безопасность:** Внедрение белого списка команд и защиты от Path Traversal.
- [x] **Базовые инструменты:** Погода, калькулятор, заметки, поиск.
- [x] **Лендинг:** Современный UI для презентации проекта.
- [ ] **Docker-поддержка:** Создание Dockerfile для быстрого развертывания одной командой.
- [ ] **Тестирование:** Увеличение покрытия тестами до 80%+.

---

## 🟡 Этап 2: Расширение интеллекта (v3.0)
*Фокус на NLP, памяти и новых источниках данных.*

- [ ] **RAG (Retrieval-Augmented Generation):** Позволить IDA читать твои локальные PDF, текстовые файлы и документы для ответов на основе твоих данных.
- [ ] **Поддержка локальных LLM:** Интеграция с Ollama (Llama 3, Mistral), чтобы IDA мог работать полностью оффлайн.
- [ ] **Система напоминаний:** Интеграция с планировщиком задач (cron/apscheduler) для активных уведомлений.
- [ ] **Мультиязычность:** Полная поддержка команд на английском, русском и якутском языках.
- [ ] **Анализ эмоций:** Определение настроения пользователя для более эмпатичных ответов.

---

## 🟠 Этап 3: Экосистема и UI (v4.0)
*Фокус на интерфейсах и интеграциях.*

- [ ] **Web Dashboard:** Полноценная веб-панель управления на React/Next.js вместо статического лендинга.
- [ ] **Telegram Bot:** Синхронизация IDA с Telegram для управления домом или сервером на ходу.
- [ ] **Голосовое ядро 2.0:** Переход на Whisper (STT) и Piper/Coqui (TTS) для качественного голоса.
- [ ] **Интеграция с Google/Apple Calendar:** Чтение и запись встреч.
- [ ] **Smart Home:** Базовая поддержка управления умными лампами/розетками (Home Assistant API).

---

## 🔴 Этап 4: Автономность и Агенты (v5.0)
*Фокус на выполнении сложных задач.*

- [ ] **Multi-Agent System:** IDA сможет делегировать задачи под-агентам (например, один ищет инфу, другой пишет код, третий проверяет).
- [ ] **Self-Correction:** Способность IDA исправлять свои ошибки в коде или командах после неудачного выполнения.
- [ ] **Browser Automation:** Выполнение задач в браузере (например, "Забронируй столик" или "Найди дешевые билеты").
- [ ] **Персональное обучение:** IDA подстраивается под твой стиль общения и предпочтения со временем.

---

## 🛠 Предложения по технологиям
- **Backend:** FastAPI (для API-режима).
- **Database:** PostgreSQL + Vector Extension (pgvector) для памяти.
- **Frontend:** Next.js + TailwindCSS + Shadcn/UI.
- **Mobile:** React Native + Reanimated (для плавного аватара).
